# Hello Git

## Nom du projet et objectif
**tp-git-intro** : mini-projet pour apprendre Git et GitHub. Il s'agit d'une page web simple intitulée « Hello Git », dont l'évolution est enregistrée avec Git et publiée sur GitHub.

## Technologies utilisées
- HTML
- CSS
- Git
- GitHub

## Ouvrir la page
Ouvrir le fichier `index.html` dans un navigateur web.

## Évolutions enregistrées dans Git
- Initialiser la page Hello Git
- Modifier le style et le titre
- Créer un style expérimental (branche `nouveau-style`)
- Résoudre le conflit sur le slogan
